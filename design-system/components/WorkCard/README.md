# WorkCard

A SpotlightCard for one shipped system: icon tile, mono kicker, title, description, an optional visual and stack chips.

**When to use.** The selected-work bento grid (6 columns at md+; cards span 2, 3 or 4).

**Props.** `icon` · `kicker` (UPPERCASE mono, e.g. "Platform") · `title` · `description` · `tags` string[] · `children` a visual — CodeWindow, FlowDiagram or LogList.

**Do.** Write the description as an outcome: what it lets partners or ops do.
