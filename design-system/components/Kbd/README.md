# Kbd

A keyboard key in mono on card, for shortcut hints.

**Props.** `children` the key text, e.g. "Ctrl / ⌘ K".

**Do.** Use inline in a sentence: "Press <Kbd>Ctrl / ⌘ K</Kbd> to navigate".
