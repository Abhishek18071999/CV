# StatGrid

A ruled row of four headline numbers, separated by 1px hairlines.

**When to use.** Once, under the hero. Two columns on phones, four at md+.

**Props.** `items` [{ value, label }] — value is short ("2+", "80.55%"), label one line of context.

**Don't.** Pad with vanity metrics; each figure must be checkable on the résumé.
