# Chip

A small mono pill for tech-stack and tag lists.

**When to use.** Under a role or a work card, one chip per technology. Group several in `.ah-chips` (6px gap; 8px under a role).

**Props.** `children` the label.

**Don't.** Make chips interactive — they're labels. Use SkillTag for the filterable list.
