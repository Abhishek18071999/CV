# Icon

Inline SVG icons: the 19 lucide glyphs and 2 Font Awesome brand marks the site uses, drawn in currentColor.

**Props.** `name` (see `Ahlawat.Icon.names`) · `size` px (default 16; 14 inline with small text, 18 in tiles) · `strokeWidth` (default 2) · `label` makes it a labelled image; otherwise it's `aria-hidden`.

**Don't.** Mix in another icon family; add a glyph from lucide at the same stroke.

_Hand-written from `artifacts/cv/src/components/cv/lucide-react 0.545.0, react-icons/fa 5.6.0`; framer-motion entrances are omitted (see Motion in the brand book)._
