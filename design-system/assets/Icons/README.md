# Icons

The 21 icons the CV uses, copied verbatim: 19 from lucide-react 0.545.0 (24px grid, 2px stroke, round caps) and the GitHub / LinkedIn marks from Font Awesome via react-icons 5.6.0.

These files are inked in Paper `primary` (#0c8861) so they read on light and dark tiles. In product code don't use them as `<img>` — use `Ahlawat.Icon`, which draws the same geometry in `currentColor` (muted-foreground by default, primary inside an IconTile).

Usage: `arrow-up-right` external links and primary CTAs · `arrow-down-to-line` résumé download · `command` ⌘K · `sun`/`moon` theme toggle · `copy` email copy · `search`/`x` filter field · `map-pin` location · `arrow-right`/`external-link` command menu · `braces`, `plane`, `file-search`, `book-open-text`, `calendar-clock`, `workflow`, `handshake`, `award` work and credential tiles · `github`, `linkedin` social links.
