# Logos

`monogram.svg` — the site favicon: a lowercase serif-italic "a" in mint #4ade9f on an Ink #0a0a0b square with 40/180 corner radius. Use at favicon and avatar sizes only; keep the Ink square, never place the bare letter on Paper. In the UI the monogram is set live in type by `Nav`. There is no wordmark: set the name in `display-hero` + `display-accent`.
